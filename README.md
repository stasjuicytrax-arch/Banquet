# Случайности

Рабочая версия сайта банкетной площадки в Перми.

- [Открыть сайт](https://stasjuicytrax-arch.github.io/Banquet/)
- [Открыть калькулятор на главной](https://stasjuicytrax-arch.github.io/Banquet/#event-calculator)
- [Сравнить шрифтовые пары](https://stasjuicytrax-arch.github.io/Banquet/design/type-pairs.html)

Главная и восемь разделов собираются командой `node scripts/build-site.mjs`. Сборка записывает готовые HTML-страницы для GitHub Pages. Облака смещаются при прокрутке между первыми двумя экранами, а галерея пространств раскрывает выбранный кадр. Шапка использует карту смещения и параметры SVG-преломления DIGITAL EVENTS. Зерно подключено общим слоем.

Калькулятор на главной пересчитывает стоимость и переносит выбранные параметры в форму заявки. Тарифы в расчёте условные. Форма готовит скачиваемый черновик в браузере. Для приёма заявок нужна подтверждённая точка назначения. Изображения площадки иллюстративные до получения материалов заказчика.
