# Случайности

Превью сайта банкетной площадки в Перми.

- [Открыть превью](https://stasjuicytrax-arch.github.io/Banquet/)
- [Открыть демонстрационный калькулятор](https://stasjuicytrax-arch.github.io/Banquet/prototype/calculator.html)

На первом экране капля увеличивает и подсвечивает часть кадра. Она плавно покачивается при открытии и реагирует на прокрутку. Облака переходят в светлый фон следующего блока. Внизу страницы есть переключатель для сравнения с облаками по всей странице.

Калькулятор показывает, как выбор формата, количества гостей, даты и организации под ключ меняет расчёт и пример заявки для менеджера. Тарифы и контактные данные в примере условные. Весь расчёт выполняется в браузере.
